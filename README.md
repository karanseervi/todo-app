# To-Do List Web App 📝

A simple task management web app built with HTML, CSS, and JavaScript. It uses localStorage to save tasks between sessions.

## Features
- Add tasks
- Mark tasks as complete
- Delete tasks
- Data saved in the browser's localStorage

## How to Use
1. Open the app in your browser.
2. Enter a task in the input field and click the **Add** button.
3. Click on a task to mark it as complete.
4. Click the **❌** button to delete a task.
